## 五、注意事项

1. **显存预算**：RTX 3060 12GB 跑 H3 需开启 CPU 离线（自动），单条 8-10 秒视频预计耗时较长，建议先跑小分辨率（如 512x896 或 640x1024）测试。
2. **H3 分工原则**：H3 只负责物理运动（眨眼、推镜、转头），画面美感问题一律回到第一步生图提示词解决。
3. **角色一致性**：固定 Seed（如 `12345`）+ 固定人物特征咒语，图库存于 `/assets/character/girl_v1/`。
4. **SageAttention** 已装（2.2.0），`MiniMaxH3SpeedCache` 默认 `auto` 模式会自动启用。
5. **输入/输出目录**：图片放 `Documents\ComfyUI\input`，成片在 `Documents\ComfyUI\output`。
6. **工作流预设**：`workflow/` 下全部工作流已预设为竖屏 9:16 / 竖图 864x1536，H3 视频统一 0.4MP 快速跑片分辨率。
